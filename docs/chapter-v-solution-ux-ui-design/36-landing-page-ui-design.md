# 5.3. Landing Page UI Design

En esta sección se presenta el diseño de la interfaz de usuario para la Landing Page de StorePulse. La propuesta busca comunicar de manera clara la solución, sus beneficios y funcionamiento, así como facilitar el acceso de los usuarios a las aplicaciones de la plataforma.

El diseño de la Landing Page considera la organización y jerarquización de la información definida para StorePulse, incorporando los principales elementos de navegación, llamados a la acción y contenidos necesarios para orientar al visitante hacia los puntos de acceso correspondientes.

## 5.3.1. Landing Page Wireframe

Se presentan los wireframes de baja fidelidad que definen la estructura base de la Landing Page de StorePulse. Estos wireframes permiten establecer la disposición de los bloques de contenido, la jerarquía de la información y la ubicación de los principales llamados a la acción (CTA), antes de incorporar los elementos visuales definitivos.

La propuesta considera las versiones para Desktop Web Browser y Mobile Web Browser, manteniendo la organización de la información y adaptando la distribución de los elementos a las características de cada tamaño de pantalla.
